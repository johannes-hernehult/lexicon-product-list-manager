# Product List Manager

A small little console app that lets you store products in memory, list all added products, search for a specific product, delete products and some statistics of all the products.

Master branch contains the latest version.

I am doing my projects in JetBrains Rider in a Linux environment, so there seems to be more files than necessary in the repo. The project is under the folder ***Week 43 - Product List Manager > Program.cs***
